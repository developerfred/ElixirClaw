# ElixirClaw - OpenClaw Node in Elixir

## Overview

ElixirClaw is a high-performance, secure node client for OpenClaw Gateway implemented in pure Elixir. It provides device capabilities (camera, screen, notifications, location) to OpenClaw AI assistants.

## Key Modules

### ElixirClaw.Gateway
WebSocket client that connects to OpenClaw Gateway (default: 127.0.0.1:18789).
- Handles connection lifecycle with reconnection
- Implements OpenClaw protocol handshake
- Manages heartbeats and message routing
- Supports node.invoke for capability execution

### ElixirClaw.Node
Executes device capabilities:
- `camera.snap` - Capture photo from camera
- `camera.clip` - Record video clip
- `screen.snap` - Screenshot
- `screen.record` - Screen recording
- `system.run` - Execute commands (with allowlist)
- `system.notify` - Send notifications
- `location.get` - Get device location
- `notifications.send` - Alias for system.notify

### ElixirClaw.Protocol
Encodes/decodes OpenClaw WebSocket protocol messages:
- connect request/response
- node.describe
- node.invoke
- heartbeat
- event messages

### ElixirClaw.Security
Security utilities:
- Input sanitization
- Command validation
- Path traversal prevention
- URL safety checking
- JSON payload sanitization

### ElixirClaw.Auth
Device identity management:
- Generate device keys
- Sign challenges
- Verify signatures
- Secure storage

## CLI Commands

```bash
# Show status
./elixir_claw status

# Register node with gateway
./elixir_claw node-register --display-name "My Node"

# Start node
./elixir_claw node-start

# Stop node
./elixir_claw node-stop

# List pending approvals
./elixir_claw approvals

# Interactive mode
./elixir_claw -i
```

## Configuration

Environment variables:
- `ELIXIR_CLAW_HOST` - Gateway host (default: 127.0.0.1)
- `ELIXIR_CLAW_PORT` - Gateway port (default: 18789)
- `ELIXIR_CLAW_NODE_ID` - Node ID
- `ELIXIR_CLAW_TOKEN` - Authentication token

Or via config file at `~/.config/elixir_claw/config.json`:
```json
{
  "gateway_host": "127.0.0.1",
  "gateway_port": 18789,
  "display_name": "ElixirClaw Node",
  "caps": ["camera.snap", "screen.snap", "system.notify"]
}
```

## Security Notes

1. **Command Allowlist**: By default, `system.run` is disabled. Add commands to `allowed_commands` in config.
2. **Path Traversal**: The security module prevents path traversal attacks.
3. **Input Sanitization**: All user inputs are sanitized before use.
4. **Secure Storage**: Device identity is stored with restricted permissions (600).
5. **Private Network**: Only connects to localhost by default.
